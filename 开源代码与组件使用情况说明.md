# Shannon OS Agent — 开源代码与组件使用情况说明

## 概述

Shannon OS Agent 是一个基于开源技术栈构建的智能服务器管理助手。本项目代码为自主开发，引用了以下开源组件和第三方服务。

***

## 一、后端 Python 依赖

| 组件            | 版本     | 许可证      | 用途                   |
| ------------- | ------ | -------- | -------------------- |
| FastAPI       | latest | MIT      | Web API 框架           |
| Uvicorn       | latest | BSD-3    | ASGI 服务器             |
| httpx         | latest | BSD-3    | HTTP 客户端（调用 LLM API） |
| aiosqlite     | latest | MIT      | SQLite 异步数据库驱动       |
| Pydantic      | latest | MIT      | 数据验证与序列化             |
| asyncssh      | latest | EPL-2.0  | SSH 客户端（异步引擎）        |
| paramiko      | latest | LGPL-2.1 | SSH 客户端（同步引擎）        |
| python-dotenv | latest | BSD-3    | 环境变量加载               |
| PyYAML        | latest | MIT      | YAML 配置文件解析          |

***
