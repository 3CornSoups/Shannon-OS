# ADR-0001: 动态探测替代静态配置注册子智能体

## 状态

已采纳（2026-05-12）

## 背景

PRD 规划了 `delegates.yaml` 静态配置注册子智能体（Phase 5 MCP 扩展架构）。但实际讨论中发现：

- 远程服务器环境各异，静态配置与实际环境可能不一致
- 多服务器场景下每台服务器可用工具不同，YAML 难以表达
- 新增子智能体需要同时改代码和 YAML，维护成本双倍

## 决策

采用**动态探测 + 自动注册**替代 YAML 配置。

每个 SubAgent 子类实现 `detect(executor) -> bool` 静态方法，通过 SSH 探测远程服务器上是否安装了对应工具（如 `which claude && claude --version`）。探测到的自动加入可用列表，探测不到的不注册。

新增子智能体只需添加一个类文件，不需改任何注册逻辑或配置文件。

## 后果

### 正面
- 零配置维护，新增子智能体只需添加类
- 每台服务器自动适配可用工具，不会误报或漏报
- 多服务器场景下各服务器独立探测，各有各的可用列表

### 负面
- 每次委托前需要 SSH 探测（约 1-2 秒），可缓存探测结果
- 无法通过配置强制禁用某个子智能体（后续可添加黑名单机制）
