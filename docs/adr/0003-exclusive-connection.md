# ADR-0003: 委托期间独占 SSH 连接

## 状态

已采纳（2026-05-12）

## 背景

Claude Code 委托任务可能持续数分钟，需要实时流式读取输出。现有的 SSH 连接池模式是「获取 → 执行命令 → 归还」，不适合长时间流式读取场景。

## 决策

委托执行期间**独占**一个 SSH 连接，不归还连接池：

1. `pool.get_connection()` 获取连接
2. 通过同一连接创建子进程执行 `claude -p`
3. 持续读取 stdout/stderr → SSE 推送到前端
4. 用户取消时通过同一连接的 `process.close()` / `SIGTERM` 终止
5. 进程结束后 `pool.release_connection()` 归还

## 后果

### 正面
- 流式输出和取消操作都通过同一连接，简单可靠
- 连接池支持多连接，委托占一个不影响其他并发操作
- 不需要额外的进程跟踪机制（PID 文件等）

### 负面
- 长时间占用一个连接，期间该连接不可用于其他操作
- 需要处理连接异常断开的情况（超时、网络中断）
